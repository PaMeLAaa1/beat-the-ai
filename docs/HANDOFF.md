## 云环境设置

1. 选择仓库 PaMeLAaa1/beat-the-ai 的 main 分支。
2. 使用 Node.js 20 或更新版本。
3. 不需要 npm install；确认 node 与 npm 可用。
4. npm run check 检查语法/引用；npm test 执行逻辑和输入测试。
5. HOST=0.0.0.0 npm start 启动云端端口预览，默认端口 3000；本地默认监听 127.0.0.1。
6. 完成平台要求的环境验证和发布，再开始游戏开发/验收任务。

首次初始化已解决「仓库无提交、main 不存在」这一阻塞。该动作本身不等于云环境已启动或网站已部署。
