# 验收清单

仅在实际执行后标注通过；当前执行情况见 HANDOFF.md。

## 自动检查

- 初始进度 100，第一条台词正确，快照不可变。
- 首击立即生效，70ms 内多次点击受节流。
- 按住在 250ms 开始重复，慢帧最多一击，松手后停止。
- 归一化坐标夹紧到 0～1，移动影响下一击位置。
- 60/24 阈值准确，台词轮换符合冷却时间。
- 900ms 无命中，连击归零。
- 伤害不穿过 0；broken/rebooting 事件每次只触发一次。
- 打爆 900ms、重启 600ms 后恢复，必须重新按下。
- 暂停释放输入；后台时间不消耗阶段，不在恢复时补打。
- 重复多轮不累计监听器或产生重复阶段事件。
- 事件回调重入被隔离，回调抛错不永久锁住游戏，dispose 可靠。
- 输入适配覆盖指针重复、非主指针、取消/失焦、Space、子按钮和销毁。
- 语法与本地资源引用检查；HTTP 能访问 HTML、JS、CSS。

## 浏览器人工验收

| 场景 | 操作与期望 |
| --- | --- |
| 首次进入 | 无开始菜单，第一眼看到 AI 标签与「替代我」主题 |
| 手机 360px/390px | 核心角色、进度和提示可见，无横向滚动；设置按钮易点击 |
| 快速点击/按住 | 每次有效命中都有反馈；进度变化与连击对应 |
| 多指/右键 | 不额外攻击；取消触摸后不持续出拳 |
| 拖出区域 | 指针释放可靠，不出现卡住的自动连击 |
| 切后台/锁屏 | 回来不补打，不自动继续上一轮 |
| 打爆与重启 | AI 求助，进度归零；新一轮需重新按下 |
| Space/Tab | Tab 可到达控制与游戏；Space 只在游戏聚焦时攻击 |
| 设置 | 点击声音/动态按钮不攻击；刷新后保持选择 |
| 减弱动态 | 系统偏好初始生效；不抖动、不大幅运动 |
| 无声音支持 | 无异常，视觉和玩法继续 |
| 连续操作 2 分钟 | 临时特效和音频声部有界，不越来越卡 |
| 页面后退/前进 | 无重复主循环，声音与设置正常 |
| 离线资产 | 没有外部字体、图片、分析或 AI API 请求 |

目标浏览器：当前 Chrome/Edge、Firefox、Safari；手机重点 iOS Safari 与 Android Chrome。自动逻辑测试不能替代这些实测。
